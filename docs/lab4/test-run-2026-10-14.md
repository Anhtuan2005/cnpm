# Kết quả kiểm thử local ngày 14/10/2026

Lệnh chạy trên Windows, SQL Server local và bản mã trong workspace trước khi đưa hồ sơ Lab 4 lên GitHub. Đây là bản ghi kết quả stdout đã quan sát, không phải log CI.

## Backend

```powershell
dotnet test test/test-cases/EcommerceApp.Tests/EcommerceApp.Tests.csproj --configuration Debug --no-restore --verbosity minimal
```

```text
Passed!  - Failed:     0, Passed:   110, Skipped:     0, Total:   110, Duration: 11 s - EcommerceApp.Tests.dll (net8.0)
```

Các bài integration test tự tạo database `TechvoraTests_*` riêng. Chúng bao gồm đăng ký, giỏ/checkout, tồn kho đồng thời, thanh toán/callback, hủy/hoàn tiền, phân quyền và phạm vi Sprint.

## Browser smoke

Ứng dụng chạy tại `http://localhost:5009` với `Release:ActiveSprint=2`, `Demo:Enabled=true`, `Database:MigrateOnStartup=true`, `Email:Enabled=false` và database demo riêng `TechvoraLab4Demo_20261014`. Test dùng Microsoft Edge.

```powershell
cd src/frontend
npm run test:smoke
```

```text
Running 22 tests using 1 worker
22 passed (1.4m)
```

Các ca bao gồm form admin, mua ngay, giỏ hàng, địa chỉ checkout, COD/VNPAY/voucher trên giao diện, so sánh sản phẩm, route Sprint 2/Sprint 3, mobile và yêu cầu hỗ trợ đến trang đơn hàng admin. Database demo không phải database production và ứng dụng thử đã được dừng sau khi chạy.

Các lệnh trên không gọi giao dịch thật đến VNPAY hoặc GHN. Cần cấu hình sandbox riêng nếu nhóm muốn demo hai tích hợp đó trước buổi báo cáo.
